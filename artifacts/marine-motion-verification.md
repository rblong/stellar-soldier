# 机枪兵动作与虫群数量专项验收

日期：2026-11-07。REQ-25/26。结果：动作、数量控制和基础密集场景验证通过。完整技能/成长系统未纳入本次验收。

## 实现与证据

- 本地原始Marine图集保持不变，以独立脚本复制至忽略目录；SHA-256与源一致，见[来源记录](marine-motion-source.json)。图集1152×896，取16方向×9帧腿部步态、待机/上身射击及死亡序列，不导入社区战斗代码。
- 上身瞄准与腿部行进方向分开。9帧按实际位移驱动，周期建议108像素；停止或顶住边界不踏步。步频不依赖渲染帧率，斜向速度归一化。
- 渲染按固定原点/尺寸分层，避免逐帧重新裁紧导致缩放跳动；步行时开火不覆盖腿部帧。后坐力不修改逻辑坐标；16方向枪口与子弹使用共用挂点，移动中的短枪口闪光跟随枪械。
- 足落地触发轻尘与短脚步声；受击短闪光/保护环；死亡立即停止战斗，再播放有限倒下表现后展示结算。暂停冻结动作/尘迹，失焦处理器清理输入/声音，重开清零步态和死亡计时。
- 缺原图或坏图时使用原创分层机枪兵，交替腿脚仍动；其他有效虫族素材继续使用。原版图像和含原版截图均不入库、不进入公开构建。
- 可见数量面板支持自定义1–300、+10/+50、清空、恢复自然生成、测试保护和滚动FPS。手动模式总量300封顶，暂停/死亡禁止加怪，清空不增加击杀，恢复默认/重开关闭保护。密集虫群采用网格软分离，玩家保留独立定位标记。

- `npm run verify:motion`：13项通过，见[动作专项JSON](marine-motion-verification.json)。无未捕获页面异常。
- `VERIFY_PREVIEW_URL=http://127.0.0.1:5181`时运行`npm run verify:browser`：原有18项检查回归通过，含公开构建自然战斗、无包/坏单项/缺声音、暂停及三次重开。
- 脚部验证从实际渲染的小兵隔离图取像素，最终采样包含全部9帧、9种不同脚部像素；不是只读取一个动画帧计数。8向按键、移动瞄准、冻结后的渲染图和坏步行图回退均检查。

## 基础密集场景

环境：Windows、Intel Core Ultra 7 255H、Chromium145.0.7632.6 headless，页面1440×1160、DPR1，战场逻辑1280×720。本地机枪兵与虫族，只有普通机枪，无5技能叠加。开启明确标注的测试保护，使用界面逐步增加至300只。

最终采样10.66秒，起始300只，采样点实际276–299只（正常击杀持续发生）；滚动rAF帧率均值约119.9、最低约118。数据来自当前设备的约1秒采样窗口，不能当作真实用户浏览器、其他设备、长期运行或完整技能版本的性能保证。未测长期内存或掉落/地图压力。
