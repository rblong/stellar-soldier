# 第1阶段：机枪射击样片验收

日期：2026-11-07。REQ-20261107-24。结果：第1阶段实现与自动化检查通过；仓库同步状态见下文。第2–5阶段未执行。

## 本轮交付

- TypeScript、Canvas 2D、Vite独立工程；2400×1600试验战场、1280×720逻辑视口、跟随相机和小地图。地面与装饰原创绘制，不复制塔防地图/业务代码。
- WASD/方向键移动、机枪自动索敌、每秒5发实体子弹、线段碰撞、射程460、两发击杀基础跳虫。
- 跳虫自然屏外生成、追击与接触攻击、生命保护、死亡统计和重开。每秒1.5只、上限60；无波次、成长、掉落或附加技能。
- 机枪兵16方向静帧、跳虫16方向×7步态的本地可选接入；缺包回退原创单位，坏单项保留其余资源。机枪兵步行仅临时起伏，不声称完整动画。
- 枪口、曳光、受击闪点/碎屑、死亡反馈、基础声音；后坐力只计算渲染偏移，不修改玩家坐标。
- Esc/按钮暂停、失焦/隐藏事件自动暂停且需手动继续、静音和音效音量保存。音乐明确未接入。
- 开发环境`?verify=1`才暴露验收接口；生产包没有可变更游戏状态的验收接口。

## 环境与命令

Windows，Intel Core Ultra 7 255H，Node.js 22.20.0；浏览器Chromium 145.0.7632.6，1440×1080、DPR1，另查800×700窗口。实际依赖版本见package-lock：本轮Vite8.3.6、TypeScript7.0.2、Playwright1.65.0。

- `npm test`：11项通过。覆盖斜向归一化/边界、线段命中、射程/两次命中、最近碰撞、受伤保护、暂停、死亡优先、合法屏外生成、数量上限/弹体到期、连续射击不漂移和新局重置。
- `npm run typecheck`：通过。
- `npm run build`：通过。36个构建文件，检查无sc-local/starcraft1路径，且所有构建文件哈希不匹配本地原版包内容。
- 开发服务5180、生产预览5181运行后，设置`VERIFY_PREVIEW_URL=http://127.0.0.1:5181`运行`npm run verify:browser`：18项通过，无未捕获页面异常，详情见[JSON](phase1-browser-verification.json)。
- 第一次构建发现一条无用CSS data import导致解析失败，已移除；修复后构建通过。第一次完整浏览器验证后增加自然生成与生产预览检查，最终18项均通过。

## 浏览器证据

- 用户点击后解锁音频并解码4类战斗声音；这不代表扬声器实听。
- 键盘D移动约0.5秒，位移110；Esc暂停后计时、玩家、虫群、子弹与效果保持不变。
- 自动射击造成实际命中/击杀；接触攻击扣血、致死结束，3次死亡重开清除本局状态。
- blur处理器通过显式派发浏览器事件验证，按键清空、游戏暂停；未进行操作系统最小化/窗口切换的人工验收。
- 静音清理活动声音，音效音量25%设置及静音可跨刷新保留。
- 强制回退、404缺manifest、单一图集请求失败、全部WAV不可用均可继续战斗。整包缺失通过请求拦截模拟，未移动/删除实际素材目录。
- 自然屏外刷怪未经调试注入可进入战斗并击杀；公开生产构建同样可自然刷怪击杀，且无验收修改接口。
- 原创回退与小窗口截图已查看，按钮、HUD、单位和小地图可见；图集按实际竖向方向/横向步态读取。
