# Original combat resources

These sprites, icons and PCM sounds were procedurally authored for Stellar Soldier on 2026-11-07 by the project's Codex workflow, using only geometric drawing and synthesized waveforms. No StarCraft images, samples, extracted frames, fonts or downloaded artwork were used to generate them.

Generator: `scripts/generate-combat-resources.py` (Python 3 and Pillow). This folder is project-authored material and can be tracked and included in the project's builds; this statement does not change any repository-wide software license. The separate `assets/sc-local/` pack remains local-only and must not be publicly distributed.

Sprite timing, palette and sounds are first-pass drafts. Assets have no gameplay logic. Dynamic lightning paths, projectile collision, muzzle attachment points and final mixing remain to be implemented and verified. Audio is PCM mono, 22050 Hz, 16-bit; listening QA is pending.
