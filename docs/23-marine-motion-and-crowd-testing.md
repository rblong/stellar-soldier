# 机枪兵动作完整性与虫群数量测试

日期：2026-11-07。REQ-20261107-25/26。状态：已实现并完成专项验证。优先于第1阶段临时起伏表现。

## 目标、范围与非目标

- REQ-25：小兵走路脚必须真实交替运动；本次将待机、步行、转向、移动射击、受击、死亡、暂停与重开作为一组检查，不能用整个人物上下浮动代替步行。
- REQ-26：玩家能控制增加虫族数量以测试动作、射击反馈及性能。
- 范围为现有射击样片的动作与测试工具。保持机枪兵身份、现有伤害/射速/移速，不提前实现8种子弹技能、装备或波次，不把基础300虫测试等同于完整游戏压力验收。

## 动作与效果规则（新增参数为待验证建议）

| 状态 | 要求 | 衔接/边界 |
| --- | --- | --- |
| 待机 | 双脚落地，保留上身持枪与最后朝向 | 无位移不循环走路，顶住地图边界也停止踏步 |
| 步行 | 按实际移动距离驱动9帧交替腿部；建议完整周期108像素 | 斜向归一化；同速斜向与直向步频一致，停下回到落脚姿态 |
| 转向 | 移动方向与瞄准方向分开 | 无目标朝移动方向；有目标上身朝敌人、腿朝实际行进方向，后退/侧移仍迈步 |
| 站立开火 | 上身举枪、短后坐力、枪口闪光及弹道衔接 | 后坐力只影响渲染、不累积；枪口挂点与子弹出生使用同一组坐标 |
| 移动开火 | 腿步态持续，上身可瞄准敌人 | 开火不能把整个人物每0.2秒切回站立、导致脚冻结；腰部重叠遮挡避免断层 |
| 受击 | 上身短闪光/保护提示，保持移动控制 | 不用重复整帧抖动移动逻辑碰撞体，不吞掉步态 |
| 脚步支援 | 轻量脚步尘点和短促脚步声，按足落地触发 | 仅真实移动；同一脚步不重复播放；音量受总静音/音效设置控制，不盖过枪声 |
| 死亡 | 停止行走/开火，短倒下反馈与结算 | 战斗立即停止；表现计时独立且有限，不继续伤害/刷怪；失焦时冻结表现 |
| 暂停/失焦 | 冻结腿、上身、枪口、尘迹、倒地表现，清理按键与声音 | 继续不补播积压脚步/枪声；重开归零步态、后坐力和死亡表现 |
| 缺素材 | 走路腿脚仍动 | 无完整本地步行图时，用原创程序化分层机枪兵；不退回会滑行的静帧 |

本地原图`Marine.png`有16方向×9步行帧、待机和攻击姿态；上一阶段只准备了单帧方向图。新增准备脚本复制原图本体至被忽略的本地包，运行时按帧坐标取图，保持固定尺寸/锚点，不修改源文件、不逐帧重新裁紧。取帧坐标参考[固定提交中的单位定义](https://github.com/GiacomoVespo/starcraft-full-html5/blob/ab3a5bf749ec56d0929d970286a059c00685e4c9/Characters/Terran.js)，只使用动作元数据，不导入其战斗实现。原版图像和含原版的验收截图不入库。

## 数量测试交互

- 在游戏下方提供“虫群数量测试”面板，明确显示测试状态；输入本次数量1–300，点击“增加虫族”，总量最多300。另有+10/+50快捷按钮、清空、恢复自然刷怪。
- 增加后切换手动数量测试，不继续自然生成；在玩家周边分布虫族，不把全部单位堆在脚下。恢复自然刷怪回到60只生成上限与1.5只/秒，超量测试虫清理后恢复，界面明确提示。
- 可选“测试保护（免伤）”，默认关闭；开启后持续显示测试标识，便于观察300虫。关闭恢复正常伤害；重开恢复默认自然生成、保护关闭。
- 暂停、未开始或死亡时禁止增加虫族；清空不算击杀、不增加战绩。非法数量不生成，不使用静默四舍五入制造意外数量。
- 显示当前虫数与滚动采样帧率（约1秒窗口），页面失焦/暂停不作为运行帧率样本。帧率仅代表当前设备/场景，不宣称跨设备性能达标。
- 密集虫群使用轻量空间网格软分离，建议中心间距20像素、每帧两轮、每轮位移上限90×dt像素；用于减轻全部叠成一团的穿模，不改变玩家可穿行规则。玩家顶部增加清晰定位标记，数量高时仍能找到小兵。
- 数量面板是样片的显式测试工具，可供试玩；开发验收接口仍只在开发模式显式verify参数下存在。
