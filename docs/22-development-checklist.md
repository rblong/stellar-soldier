# 开发计划与验收清单

日期：2026-11-07。REQ-20261107-24。目标：分阶段交付机枪兵持续射击虫族的独立生存游戏。最新安排：今晚完成第1阶段、执行验证并同步仓库；后续阶段按依赖推进，不承诺未验证的完成时间。

## 范围、规则与交互

本清单管理实施顺序，不改变[子弹技能](21-bullet-skills.md)、[虫族与生存分类](19-requirements-index.md)及[资源边界](20-graphics-audio-resources.md)。所有数值仍为待验证建议。第1阶段采用TypeScript、Canvas 2D及Vite，小型测试战场建议2400×1600、逻辑视口1280×720；完整6144×6144地图与45秒波次留到第4阶段。

第1阶段：生命120、移动220、伤害12、射速5发/秒、射程460、子弹速度1000、受伤保护0.5秒；跳虫生命24、接触伤害8、速度110、攻击间隔1秒。建议每秒生成1.5只、同时最多60只，从屏外可达位置进入，死亡结束，不作无限波次已实现的承诺。没有经验、水晶、掉落或技能效果。

WASD/方向键移动，自动瞄准射击；Esc/按钮暂停，失焦自动暂停后手动继续；死亡后重开。本阶段提供总静音和音效音量；音乐明确显示未接入，独立音乐音量留到第5阶段。提供程序化单位开关，以及仅开发环境、显式verify参数才启用的验收接口。
