日期：2026-11-07。REQ-20261107-23。状态：设计＋首批资源制作，未实现游戏逻辑。全部新增数值为建议，等待试玩。

## 1. 目标、范围与非目标

机枪兵的本质不变：持枪、瞄准、连续射出实体子弹、击中虫族。成长主要改变子弹的穿透、弹射、命中爆炸、附加电弧和状态，而非把角色变成施法者。保持同一主体与枪械轮廓，强度通过枪口、弹道、冲击、虫族反馈、声音表达。

首版建议8项附加技能池，随机芯片学习，最多5项同时生效，均自动触发。取代[旧技能示例池](16-marine-survival-concept.md#53-初版技能池示例数值)与1–5主动施法方案；不加入召唤、轨道轰炸、手动投掷、换职业或技能升级。旧掉率2%/20%/100%、同名不可重复学习、放回不重随机、遗忘/替换及死亡清空继续有效。

装备主武器解释为机枪组件，提升伤害/射速/词条，仍发射机枪弹。实弹/热能/电磁是弹药与命中表现倾向，取代旧等离子枪/电弧枪直接替换机枪普攻的初版设想。传奇额外弹道另立触发来源，与技能组合统一受§4约束。

## 2. 基础射击与打击链

建议沿用生命120、移速220、基础伤害12、射速5发/秒、射程460。新增子弹速度1000像素/秒、寿命0.6秒、逻辑碰撞半径3，达到射程即回收；碰撞用上一位置至当前位置的线段检测，避免高速穿过小跳虫。射击时锁定方向，首版不追踪转弯、不重新寻敌；无敌人不空射。暴击每颗原始子弹判定一次，适用基础暴击倍率150%及总暴击率50%上限。

一次完整反馈：枪口约40毫秒闪光 → 短曳光朝敌人移动 → 碰撞点火花约100毫秒 → 虫族受击闪白约60毫秒/可选小幅躯体震动 → 击杀时短促虫族死亡反馈。后坐力只移动渲染节点，不移动主角碰撞体，反复射击须回到固定挂点。装甲厚重感使用火花与声音，不擅加未设计的减伤。

枪口挂点需按16方向校正；现有96×96图集的透明画布边缘不等于枪口。先制作挂点校准页，保留偏移配置。子弹渲染与判定使用世界坐标，相机移动不改变射程。伤害由模拟发出命中事件，特效监听事件；动画结束不能决定命中。

## 3. 首版8技能详细表

以下D为该次原始子弹的最终直接伤害（含该弹暴击及重击倍率）。二次伤害不再暴击，不二次套用武器百分比。随机触发按每颗原始子弹最多一次；未命中不触发命中类技能。

| ID / 技能 | 触发与建议数值 | 子弹、命中和虫族表现 | 音频 / 首批资源 |
| --- | --- | --- | --- |
| pierce / 穿透弹 | 每颗子弹额外穿透2名敌人；最多直接命中3名，各100%D；同弹同目标一次 | 弹芯加长、细白尾线；穿出时两端碎屑，不拉成贯穿全屏激光 | 普通枪声＋轻破甲声；`bullet-pierce`、`impact-kinetic` |

| explosive / 爆裂弹 | 第一直接命中时25%概率，半径70，最多命中8名周边敌人，各50%D；排除原直接目标；全技能内部冷却0.15秒 | 弹头橙色小点；命中瞬间小火核＋扩散冲击环＋短烟；爆炸边界对应实际半径 | 低频冲击＋短噪声；`impact-explosion`，本地可用`sc-explosion` |
| arc / 电弧弹 | 第一直接命中时20%概率，半径140内最近2名其他敌人，各40%D；不连锁；内部冷却0.2秒 | 子弹仍是机枪弹，仅加青白电芯；命中后出现约0.12秒的分叉折线，端点小火花 | 电噼啪短声；`impact-electric`＋运行时程序化折线 |
| incendiary / 燃烧弹 | 第一直接命中附加2秒灼烧，每0.5秒10%D，共4跳；同技能同目标刷新时长、不叠层、不立即补跳；保留较高DOT强度 | 短橙尾线；命中火星；虫体局部小火苗，不生成地面火海 | 轻火星声；`bullet-fire`、`impact-fire`、`status-burn` |
| cryo / 冷凝弹 | 第一直接命中减速25%持续1.5秒；同技能刷新不叠层，Boss降为10%；不冰冻、不增加伤害 | 短蓝白尾线，命中碎晶；脚下断续霜环＋状态图标，仍看得清虫族朝向 | 玻璃质短声；`bullet-cryo`、`impact-cryo`、`status-slow` |
| heavy / 重击弹 | 每第5颗发出的原始子弹为重击弹，该弹直接伤害乘150%后计入D；命中普通/精英击退18像素，Boss免击退；不穿墙 | 更粗但不放大主体的曳光，明显十字火花；仅此弹可有极轻镜头反馈 | 较低沉枪声；`bullet-heavy`、`impact-heavy` |
| overdrive / 战术装填 | 普攻射速+25%，仍遵循总上限12发/秒；不引入弹匣/换弹计时 | 弹体无额外颜色；枪口节奏更紧、机匣短亮点；命中仍由其他技能决定 | 复用枪声并限流，不每帧播放；`muzzle-flash`、`skill-overdrive` |

所有ID稳定，名称可调；技能面板明确显示“自动附加”。重击计数按本局已发射原弹累积取模5，无技能时也累计，避免遗忘重学刷首发；遗忘不刷新爆裂/电弧内部冷却。数值、掉率、池权重均可数据化，初版8项等权，不增加升级三选一。

### 3.1 每项技能的制作步骤

- 穿透弹：复用基础弹体，增加长尾；保存命中ID集合，按沿运动线的距离顺序结算。资源主要是弹芯与细碎屑。
- 跳弹：在命中事件选取确定的新目标，生成带原始来源ID的衍生实体弹；朝向更新只在生成时发生。折线不是伤害范围。
- 爆裂弹：先结算直接伤害，再发范围事件；视觉由火核、冲击环、碎屑组成。原版爆炸9帧可作本地版本，原创8帧作回退，不能把帧数当作命中次数。
- 电弧弹：选好目标再画首尾固定的3–5段折线，中间点可有少量随机偏移；首尾须精确落在目标上。二次目标立即结算，0.12秒连线仅反馈，不创建持续伤害区域。
- 燃烧弹：发状态事件，目标身上挂火苗；每跳显示小型伤害反馈，死亡立即解绑。首版不制作全身燃烧动画。
- 冷凝弹：发减速状态，脚下霜环随敌人移动；到期移除，移速从基础值重算，不反复乘系数。
- 重击弹：复用基础弹体和命中特效，改宽度/火花形状/音调；击退由碰撞规则处理，视觉震动不代替击退。
- 战术装填：更新发射间隔，复用枪口和音效；射速变快不能让音频并发无限增长。

## 4. 组合、结算与遗忘边界

1. 发射时快照装备、技能和D所需参数；原始子弹分配`shotId`，衍生事件继承`shotId`并标记来源。视觉随机数与战斗随机数分开。
2. 直接命中按距离排序，先结算原弹伤害。仅第一次直接命中可触发跳弹/爆裂/电弧/燃烧/冷凝，穿透后的第二、第三目标只受直接伤害。规则偏保守，避免穿透把所有附加放大三倍。
3. 同一次第一直接命中可同时触发多个已学技能。原目标被击杀时仍可生成爆裂、电弧和跳弹；不对已死亡原目标附加状态。爆裂/电弧选取当前存活敌人，各按距离与实体ID稳定排序。
4. 跳弹、爆炸、电弧、DOT和装备生成的额外子弹均为二次效果，不触发本表任何命中附加、暴击、额外弹道或第三代效果。传奇蜂群弹额外两弹只造成直接伤害，不计重击计数；统一禁止触发递归。
5. 忘记技能立即取消该技能尚在飞行的专属衍生弹、挂载DOT/减速和待执行事件；已发射原弹移除对应修饰，保留基础弹。其他技能的效果继续。装备卸除按同一来源清理，不回滚已经结算的伤害。
6. 地面芯片学习/替换原子完成，最多5项；取消无改变。暂停时子弹、状态、内部冷却和效果时间冻结；死亡/重开清理全部子弹、状态、延迟事件和声音句柄。

组合示例：穿透＋爆裂＋电弧＋燃烧＋装填，保留机枪连续射击感，第一目标可同时出现火核与短电弧，后排承受穿透；用冷凝换燃烧可牺牲DOT换走位空间。爆裂与电弧分别处理目标，重合目标可各受一次伤害，不能再次触发效果。

## 5. 画面层级与资源制作

层级建议：地面/阴影 → 霜环与落地痕迹 → 虫族/机枪兵 → 弹道/命中 → 血条、精英标志与Boss危险预警 → HUD。Boss预警始终清晰，火焰与电弧不能遮掉危险边界。主体16方向按纹理帧切换，禁止用同一张像素人物连续旋转替代方向帧。

首批原创资源由[scripts/generate-combat-resources.py](../scripts/generate-combat-resources.py)生成：8帧横排命中图集（64×64/帧）、4帧枪口、单帧弹体、状态图和8个技能图标，以及短WAV反馈。具体文件与帧尺寸见[manifest](../public/assets/combat/manifest.json)。电弧连线、弹道长度、范围边界由运行时几何构建；图集是表现组件，不是完整技能动画或碰撞规则。

已有塔防机枪兵只有16方向×1帧；新游戏步行多帧尚缺。原型可通过小幅步行起伏和脚下尘迹表达移动，文档与版本说明须明确为临时表现。不得声称这些资源包含跑步/投掷/完整受击动作。

建议预算：同时最多256颗弹、600个装饰粒子、24个命中特效实例；超额回收最老装饰，不漏结算伤害；二次命中最多8目标。低特效保留弹芯、命中闪点、状态标记与危险预警，去掉烟、碎屑和震屏。数值需在300虫族场景测量后调整，不是已达到的性能。

## 6. 音频设计

连续枪声是主节奏；命中反馈比枪声轻，爆裂低频短冲击，电弧高频短噼啪，冷凝清脆、燃烧轻噪声。避免每次普通命中播放完整虫族惨叫。建议枪声最短间隔80毫秒，普通命中60毫秒、虫族死亡120毫秒，效果总并发12路，其中预留2路给危险/死亡；机枪兵语音至少间隔1.5秒。音效被限流只影响声音，不影响射击或命中。

总静音、音效与音乐独立音量；首次真实手势后解锁音频。失焦或暂停停止战斗循环音，不重播暂停期间事件。所有音频不可用时保持视觉反馈与正常战斗。首批合成WAV仅为可试听草稿，正式混音须扬声器实听验证。

## 8. 验收标准

- 不学技能时依然是机枪自动射击；学技能后主体与持枪轮廓不变，至少能分清普通/爆裂/电弧命中。
- 穿透同弹最多3个不同目标；跳弹最多1次；二次效果不递归；全5技能组合伤害可追踪至唯一shotId。
- 爆裂原目标不重复受范围伤害；电弧最多2个额外目标；燃烧4跳、刷新不立刻补跳；Boss冷凝减速为10%且免重击击退。
- 每第5颗原弹重击；射速受12发/秒上限；遗忘重学不刷新计数或内部冷却。
- 遗忘取消对应在途/状态/延时效果，暂停冻结，死亡/重开后无弹体、DOT、减速、音频或引用残留。
- 资源文件、帧尺寸、透明通道和WAV格式可检查；有包/缺包/单资源坏包都可完成射击与死亡重开。
- 低特效和静音仍能识别命中与危险；300虫族压力场景记录设备、分辨率、采样时长与帧率；听感另做实听。
- 当前仅文件/设计验收；以上游戏检查全部待实现后执行。
